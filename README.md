# Skin-Cancer-Class-Transfer-Learning-XAI
This repository presents a deep learning project for skin cancer classification using CNN, VGG16, ResNet50, EfficientNet-B0, EfficientNetV2-B0, and Vision Transformer (ViT). It also applies Explainable AI techniques such as Grad-CAM, LIME, and attention maps to improve prediction transparency using the ISIC skin lesion dataset.
